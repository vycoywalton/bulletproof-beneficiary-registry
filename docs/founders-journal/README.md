# Bulletproof OS Founder Journal

## Mission

Build Bulletproof OS: a trusted platform that helps individuals discover potential life insurance beneficiary rights and preserve life insurance legacy information.

## North Star

No rightful beneficiary should miss a life insurance benefit because they did not know where to look or how to begin.

## Product Focus

Phase 1:
- Life Insurance Beneficiary Search
- Life Insurance Legacy Registry

## Founder Principles

- Build trust first
- Protect user privacy
- Start focused, expand intelligently
- Document decisions
- Build for universal accessibility
